    Module 1 — Foundations#

    ECE 343 · Module 01

    Foundations

    Fields, phasors, and the transmission line: the first place a circuit stops behaving like one.

    Lessons 1–16 · Intro to Electromagnetics · Maj Ellis · Dr. Neil Rogers

    Where This Module Goes

    What electromagnetics is for, the language of fields and phasors, and the transmission line: wave propagation, reflection, impedance matching, the Smith chart, and transients, measured on a network analyzer in the first lab.

    Chapter 1: Introduction

    1. I can articulate what I will learn and how I will be assessed in this course.
    2. I can articulate practical applications of electromagnetics.

    Chapter 2: Fields

    1. I can recall the definition of scalar fields, vector fields, phasors, and Euler's identity.
    2. I can explain the basic terms and quantities used to describe electromagnetic fields.

    Chapter 3: Transmission Lines (3.1-3.4)

    1. I can describe the origin of the transmission line equation, understand the method of developing a solution, and interpret the solution.
    2. I can explain the physical meaning of and calculate the following quantities: propagation constant, phase constant, attenuation constant, characteristic impedance, VSWR, reflection coefficient, and transmission coefficient.
    3. I can use the transmission line equation to calculate the voltage/current at an arbitrary point on a specified transmission line.
    4. I can use the transmission line equation to match a load to a source using a length of transmission line.

    Chapter 3: Transmission Lines (3.5-3.8)

    1. I can identify the various quantities represented on the Smith Chart.
    2. I can use a Smith Chart to design a matching network for a given source and load, using series components, parallel components, shorted stubs, and open stubs.
    3. I can plot the transient response of a load connected to a source through a transmission line.
    4. I can measure the reflection coefficient across a range of frequencies and interpret the measurement using a network analyzer.
